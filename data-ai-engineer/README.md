# Data AI Engineer — Website

**Description:** Personal website of a Data + AI Engineer working on DataStage/CDC, Teradata → Spark Delta migration, PySpark, Databricks, GCP BigQuery, Airflow/Control-M, and RAG proof-of-concepts. Static site, no build step.

## What's inside

- `index.html` — single-file build (open directly in a browser)
- `src/` — split build: `src/index.html`, `src/css/styles.css`, `src/js/data.js`, `src/js/app.js`
- `docs/` — audit report, content checklist, deploy guide

## Run it

```bash
python3 -m http.server 8000
```

Edit the `CONFIG` block in `src/js/data.js` (email, LinkedIn, GitHub, résumé URL) to personalise.
