Metric Catalog for raw_crs_ros_prfl

The 9 operational dimensions tracked per batch.

Metric Source / Expression What It Detects
row_count COUNT(*) Missing ingestion files, truncated feeds, sudden duplicate drops
null_rate AVG(IS_NULL(profile_id, cust_id_num)) Source schema shifts, API payload renaming, missing mandatory fields
duplicate_rate 1 - (COUNT(DISTINCT profile_id)/COUNT(*)) Accidental file resends, replay attacks, duplicate landing loads
distinct_keys_ratio COUNT(DISTINCT cust_id_num)/COUNT(*) Customer key collapse, spam dummy IDs, cardinality distortion
runtime_min Job run duration DB contention, Spark cluster throttling, hung batch jobs
late_minutes Delay past scheduled SLA Upstream SFTP or source data readiness lag
